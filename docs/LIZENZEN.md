Der Release-Vault-Schriftzug basiert auf **Orbitron Bold**. Orbitron ist unter
der SIL Open Font License 1.1 veröffentlicht. Copyright 2018 The Orbitron
Project Authors; Reserved Font Name „Orbitron“. In der App wird der finale,
unveränderte CI-Schriftzug als Grafik verwendet.

Die für die PDF-Erzeugung eingebetteten **Roboto**-Schriftdateien stehen unter
der beigefügten Apache License 2.0.
