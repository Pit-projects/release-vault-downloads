# Haftungshinweise

Die App ersetzt keine individuelle Rechtsberatung. Für Inhalt, Auswahl und
konkrete Verwendung der Vertragsvorlagen ist die nutzende Person verantwortlich.

Release Vault befindet sich als Beta-Version in der Erprobung. Vor einem
produktiven Einsatz müssen die für den jeweiligen Anwendungsfall benötigten
Vertragstexte und rechtlichen Anforderungen eigenverantwortlich geprüft werden.
