# Privacy policy

[Deutsch](../DATENSCHUTZ.md) | **English**

By default, Release Vault processes personal, contract, location, and signature
data exclusively on the device in an encrypted database.

Cloud backups and device synchronization through Nextcloud are optional. The
data intended for these functions is encrypted locally before transmission.
The app can be used without a cloud connection and without a central user
account.

Location data is recorded only after the user explicitly chooses to do so.
Personal data can be exported or deleted using the privacy functions provided
within the app.

Further technical information is available under
[Local storage, encryption, and Nextcloud](DATA_STORAGE.md).
