# Privacy policy

[Deutsch](../DATENSCHUTZ.md) | **English**

By default, Release Vault processes personal, contract, location, and signature
data locally and in encrypted form on the device.

Cloud backups and device synchronization through **Nextcloud, Google Drive, or
Dropbox** are optional. Only one provider can be connected at a time. Backup
and synchronization data is encrypted locally before transfer. Google Drive
uses a visible `Release Vault` folder; the previous hidden app-data area can
also be read to migrate older data. Dropbox uses only its own app folder.
When Nextcloud synchronization is enabled, completed contracts are also
stored as **unencrypted PDF copies** in the `Releases PDF` folder. The app
can be used without a cloud connection or a central user account.

Location data is recorded only after the user explicitly chooses to do so.
Selected location coordinates are sent to Open-Meteo for the daily forecast.
If an address is explicitly opened in Google Maps, it is passed to Google Maps
only then. The optional remote-signing feature sends the contract data needed
for signing to the signing service. Personal data can be exported or deleted
using the privacy functions provided within the app.

Further technical information is available under
[Local storage, encryption, and cloud providers](DATA_STORAGE.md).
